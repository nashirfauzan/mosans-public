# MoSans (Motret Santai'S)

Aplikasi desktop untuk fotografer — memantau folder foto dan mengunggahnya ke
FotoYu secara otomatis.

**Unduh installer:**
👉 **[github.com/nashirfauzan/mosans-public/releases/latest](https://github.com/nashirfauzan/mosans-public/releases/latest)**

---

## Pilih berkas sesuai komputermu

| Komputermu | Berkas yang diunduh | Ukuran |
|---|---|---|
| **Windows 10 / 11** (64-bit) | `MoSans-Setup-<versi>-win-x64.exe` | ~220 MB |
| **Mac** Apple Silicon (M1/M2/M3/M4) | `MoSans-<versi>-mac-arm64.dmg` | ~220 MB |
| **Mac** Intel | `MoSans-<versi>-mac-x64.dmg` | ~247 MB |

`<versi>` adalah nomor versi rilis, misalnya `3.1.1`.

### Belum yakin Mac kamu yang mana?

Klik logo Apple di pojok kiri atas → **About This Mac**:

- tertulis **Chip: Apple M1 / M2 / M3 / M4** → pakai `mac-arm64`
- tertulis **Processor: Intel** → pakai `mac-x64`

## Setelah dipasang

Saat pertama dibuka, MoSans menampilkan **layar aktivasi**. Ada dua pilihan:

**Mencoba dulu (uji coba 72 jam)**
Klik **Mulai uji coba**. Semua fitur terbuka selama 3 hari, tanpa perlu apa pun.
Uji coba dihitung per perangkat dan **tidak bisa diulang** di perangkat yang sama.

**Sudah punya kunci lisensi**
Tempelkan kunci ke kolom yang tersedia lalu klik **Aktifkan**. Bentuk kuncinya:

```
MSNS-XXXXX-XXXXX-XXXXX-XXXXX
```

Lisensi terikat pada satu perangkat. Kalau kamu ganti komputer, hubungi penjual
untuk memindahkannya.

## Ada masalah?

**Windows: muncul "Windows protected your PC"**
Normal untuk aplikasi yang belum ditandatangani. Klik **More info** → **Run anyway**.
Langkah lengkapnya di [panduan Windows](INSTALL-WINDOWS.md).

**Mac: muncul "cannot be opened because the developer cannot be verified"**
Normal untuk aplikasi yang belum dinotarisasi Apple. Klik kanan ikon MoSans →
**Open** → **Open**. Langkah lengkapnya di [panduan macOS](INSTALL-MACOS.md).

**Tidak bisa aktivasi**
Pastikan kunci diketik lengkap dan komputer terhubung internet. Kalau tetap
gagal, kirimkan nomor pesan galatnya ke penjual.

**Antivirus memblokir installer**
Beberapa antivirus menandai installer yang belum ditandatangani. Tambahkan
pengecualian untuk berkas installernya, lalu jalankan lagi.
